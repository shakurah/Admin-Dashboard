# Admin Dashboard

A clean static admin dashboard layout built with HTML and CSS.

## Project Overview

This project includes a responsive dashboard interface featuring:
- A left sidebar with navigation links and action sections.
- A top header with search, notifications, user info, and action buttons.
- A main content area displaying project cards.
- A right-side panel for announcements and trending profiles.

## Files

- `index.html` - Main dashboard markup.
- `styles.css` - Layout, typography, and styling rules.
- `img/` - Image assets used in the dashboard UI.

## How to Preview

1. Open `index.html` in a modern browser.
2. Alternatively, use a local web server for a more realistic preview.

## Features

- Grid-based page layout using CSS Grid.
- Sidebar navigation with icon labels.
- Search input and user section in the header.
- Card-style project previews in the main content area.
- Announcement and trending panels on the right.

## Notes

- The project is static and does not include JavaScript or backend logic.
- Image sources are loaded from the local `img/` folder.
- The design uses the Roboto font from Google Fonts.

## Customization

To customize the dashboard:
- Update the navigation items in `index.html`.
- Edit `.card` content for project descriptions.
- Change colors and spacing inside `styles.css`.
- Replace images in the `img/` folder with your own assets.
